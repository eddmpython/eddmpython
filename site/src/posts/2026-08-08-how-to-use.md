DartLab, Codaro, xlpod, pyproc. 넷을 늘어놓으면 어디부터 열어야 할지 모르겠습니다.
보통 이럴 때 문서를 읽고, 설치하고, 안 맞으면 지웁니다. 그 순서를 뒤집는 게 이 글의 요지입니다.

**아무것도 설치하지 말고 먼저 눌러 보세요.** 랜딩의 제품마다 실행 셀이 붙어 있고,
그건 그림이 아니라 진짜 Python 입니다.

## 브라우저에서 먼저 확인합니다

DartLab 은 Python 라이브러리입니다. 원래는 이렇게 씁니다.

```
pip install dartlab
```

그런데 이걸 깔기 전에 맞는 도구인지 알고 싶습니다. 랜딩의 DartLab 섹션에서 실행을 누르면
브라우저 탭 안에 Python 이 뜨고, 거기서 DartLab 이 설치되고, 실제 공시 데이터가 나옵니다.
여러분 컴퓨터에는 아무것도 남지 않습니다.

```python
import dartlab

c = dartlab.Company("005930")
c.panel("ratios")
```

종목코드를 바꿔서 다시 눌러도 됩니다. 이게 맞는 도구인지 판단한 다음에 `pip install` 로
넘어가면 됩니다.

같은 방식으로 Codaro 섹션에는 학습 카드 예제가, xlpod 섹션에는 시트 한 장을 다루는 계산이,
pyproc 섹션에는 상태가 유지되는지 확인하는 셀이 있습니다. 전부 눌러 볼 수 있습니다.

## 셀 넷이 같은 컴퓨터를 씁니다

여기가 이 페이지의 진짜 구조입니다. 네 개 셀은 각자 도는 게 아니라 **하나의 Python 머신**을
나눠 씁니다. 그 머신을 띄우는 게 pyproc 입니다.

확인해 보세요. DartLab 셀을 먼저 실행하고, pyproc 섹션에서 "위 셀이 남긴 것" 을 누르면
DartLab 셀에서 만든 변수가 그대로 나옵니다. 페이지를 새로 고치지 않는 한 값이 남습니다.

pyproc 셀의 "상태가 남는다" 를 두 번 누르면 숫자가 1 에서 2 로 올라갑니다. 서버에 저장하는 게
아니라 브라우저 안 머신이 기억하는 겁니다.

이게 DartLab, Codaro, xlpod 밑에 공통으로 깔린 실행 방식입니다. 셋 다 "Python 을 어디서 돌릴
것인가" 라는 같은 문제를 풀어야 했고, pyproc 이 그 답입니다.

## 브라우저에서 안 되는 것도 있습니다

여기서 한계를 분명히 하겠습니다.

**Chromium 계열이 필요합니다.** Chrome 이나 Edge 에서 열어야 합니다. Firefox 와 Safari 는
지원하지 않고, 이건 결함이 아니라 범위 선택입니다.

**첫 실행은 기다려야 합니다.** Python 런타임을 내려받기 때문에 처음 한 번은 시간이 걸립니다.
DartLab 처럼 패키지까지 설치하는 셀은 30초 정도 봅니다. 두 번째부터는 바로 돕니다.

**내 파일은 브라우저가 못 엽니다.** 이게 갈림길입니다. 예제로 확인하는 단계는 브라우저에서
끝나지만, 내 컴퓨터의 엑셀 파일을 열거나 매일 새벽에 자동 실행하려면 그 단계에서 각 제품의
정식 진입점으로 넘어가야 합니다.

## 어디로 넘어가면 되나

하려는 일에 따라 갈라집니다.

**공시와 재무를 다룬다면 DartLab.** `pip install dartlab` 로 시작합니다. 종목코드 하나로
재무제표, 비율, 신용위험, 산업 위치까지 같은 문법으로 이어집니다. 한국 DART 와 미국 SEC EDGAR
를 같은 방식으로 씁니다.

**Python 을 배우는 중이라면 Codaro.** 브라우저에서 바로 열립니다. 문법 목차가 아니라 남길
결과를 기준으로 레슨이 짜여 있고, 실제 파일과 예약 실행이 필요해지면 그 상태 그대로 Local
스튜디오로 넘어갑니다.

**엑셀과 구글 시트를 오간다면 xlpod.** 원본 파일을 그대로 열고, 셀 수식 안에서 Python 을
돌리고, 결과를 원본에 되돌려 저장합니다. 새 포맷으로 옮기지 않습니다.

**Python 실행 환경 자체가 필요하다면 pyproc.** `npm install pyproc` 로 여러분 앱에 붙입니다.
서버 없이 브라우저 안에서 CPython 을 돌리고, 그 상태를 탭이 닫혀도 유지합니다.

## 오늘 할 일 하나

[eddmpython.com](https://eddmpython.com) 을 Chrome 에서 열고, DartLab 섹션의 실행 버튼을
누르세요. 종목코드를 여러분이 아는 회사로 바꿔서 한 번 더 누르세요.

거기서 나온 결과가 쓸 만하면 그때 설치하면 됩니다.
