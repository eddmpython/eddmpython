어제 재고표와 오늘 재고표를 받았는데 상품 순서가 다릅니다. 같은 줄끼리 비교하면 값이 바뀐 상품과 자리만 옮긴 상품이 섞입니다. 상품코드로 같은 상품을 찾은 뒤 재고와 단가를 비교해야 합니다.

맨 위 도구에서 파일 두 개를 고르면 이전 값과 이후 값, 원본 행 번호가 담긴 `엑셀_변경내역.xlsx`를 받을 수 있습니다. 설치와 가입은 필요 없으며, 선택한 파일은 서버로 전송하지 않고 브라우저에서 읽습니다. 기밀 파일은 회사에서 허용한 도구인지 먼저 확인해 주세요

## 엑셀 파일 비교 예제

### 행 순서가 달라도 상품코드가 같으면 같은 상품으로 비교합니다

![예제 재고표 비교 결과에서 변경 1개와 추가 1개와 삭제 1개와 동일 2개 항목이 표시된 화면](https://huggingface.co/datasets/eddmpython/eddmpython-media/resolve/main/objects/sha256/9f/9ff044d69605c8243f291ddb6a2251df9c3eff82807ffd499759aa3e79ef1c99.png "예제에는 변경·추가·삭제 상품이 하나씩 있습니다")

[맨 위 비교 도구](#excel-compare)의 `예제로 시작`을 누르면 `재고_이전.xlsx`와 `재고_이후.xlsx`를 불러옵니다. `같은 항목을 찾을 기준 열`에 `상품코드`가 선택됐는지 보고 `변경 내역 찾기`를 눌러 보세요

결과는 변경 1개, 추가 1개, 삭제 1개, 동일 2개입니다. `0012`의 재고는 30에서 24로, 단가는 18000에서 19000으로 바뀌었습니다. 두 값이 바뀌었지만 같은 상품이므로 변경 항목은 1개입니다. `0013`은 첫 줄로 옮겨졌을 뿐 값은 같아서 동일 항목으로 셉니다.

예제를 직접 열어 보려면 도구의 `이전 파일 예제 내려받기`와 `이후 파일 예제 내려받기`를 누릅니다. 실제 거래 내역이 아닌 연습용 표이며, 상품코드 `0012`는 앞의 0까지 문자로 저장돼 있습니다.

## 내 파일 선택

### 비교할 시트와 제목 행을 고르면 읽은 표를 확인할 수 있습니다

![이전 파일과 이후 파일에 재고 파일 이름과 시트 선택 및 제목 행 선택이 표시된 화면](https://huggingface.co/datasets/eddmpython/eddmpython-media/resolve/main/objects/sha256/24/24fac3bec0bc331b72dbc1151098f60da00f9ac11216137f4967c9067474feca.png "이전과 이후를 바꾸면 추가·삭제와 값의 방향도 바뀝니다")

[비교 도구](#excel-compare)의 `이전 파일`을 눌러 기준이 될 파일을 고르고, `이후 파일`에는 새로 받은 파일을 넣습니다. 암호가 없는 `.xlsx` 파일을 사용합니다. `.xls`나 CSV라면 Excel에서 연 뒤 `다른 이름으로 저장`으로 `.xlsx` 복사본을 만들어 주세요

파일 아래의 `시트`에서 비교할 표가 있는 시트를 고릅니다. 한 파일에 시트가 여러 개 있어도 이번 비교에서는 고른 시트 하나만 읽습니다. `상품코드`, `재고` 같은 열 이름이 3행에 있다면 `제목 행`도 `3행`으로 바꿉니다. `읽은 표 확인`을 열어 열 이름과 처음 세 행이 의도한 표인지 확인합니다.

파일 하나는 10MB까지, 선택한 시트는 데이터 20,000행과 100열, 전체 300,000칸까지 받습니다. 제한을 하나라도 넘으면 비교를 멈추고 안내를 띄웁니다. 큰 파일은 필요한 시트와 행 범위를 새 파일로 저장해 비교합니다.

## 같은 행을 찾을 기준

### 상품코드처럼 같은 항목을 찾을 값을 기준 열로 고릅니다

![같은 항목을 찾을 기준 열에 상품코드가 선택되고 비교할 값 열에 상품명과 재고와 단가와 담당자가 선택된 화면](https://huggingface.co/datasets/eddmpython/eddmpython-media/resolve/main/objects/sha256/6f/6fda0663d76f360e1c47b2407996a7a48ab4de6510e4bbcb04be8dde2967f86b.png "기준 열은 행을 찾고, 값 열은 바뀐 내용을 찾습니다")

[비교 도구](#excel-compare)의 `같은 항목을 찾을 기준 열`은 두 파일에서 같은 대상을 찾을 때 씁니다. 재고표라면 상품코드, 직원 명단이라면 사번처럼 대상이 그대로일 때 바뀌지 않는 값을 고릅니다. 행 번호는 정렬하면 달라지므로 기준으로 쓰지 않습니다.

한 상품을 창고마다 한 줄씩 적었다면 상품코드만으로 각 행을 구별할 수 있을까요? 코드가 두 번 나오므로 어느 창고의 행인지 정할 수 없습니다. 이때는 `상품코드`와 `창고`를 함께 고릅니다. 도구는 두 값의 조합으로 행을 찾습니다.

선택한 기준 값이 중복되면 비교를 멈추고 파일 이름과 원본 행 번호를 알려줍니다. 기준 값을 비운 행도 같은 방식으로 안내합니다. 중복 행을 임의로 지우기 전에 기준 열을 더 골라 구별할 수 있는지 확인해 주세요

## 비교할 값 열

### 재고와 단가만 고르면 두 열에서 바뀐 값만 찾습니다

![비교할 값 열에서 재고와 단가를 고르는 체크박스 화면](https://huggingface.co/datasets/eddmpython/eddmpython-media/resolve/main/objects/sha256/77/774dbf6720d8b9863b097caef9b10c2bdaa802716090b33111e15b79e86de873.png "기준 열로 찾은 같은 상품에서 무엇을 비교할지 고릅니다")

[비교 도구](#excel-compare)의 `비교할 값 열`에서는 확인할 내용만 남깁니다. 재고와 단가만 검토한다면 두 열만 체크합니다. 상품명이나 담당자가 달라져도 선택하지 않은 열은 변경 항목 수에 반영하지 않습니다.

두 파일에 이름이 같은 열만 선택할 수 있습니다. 한쪽에만 있는 열은 화면과 결과 파일에 비교 제외로 표시합니다. 비교하려던 열이 선택 목록에 없다면 양쪽 파일의 열 이름과 제목 행부터 확인합니다.

## 바뀐 값 확인

### 변경만 고르면 이전 값과 이후 값을 나란히 볼 수 있습니다

![변경 필터에서 상품코드 0012의 재고 30과 24 및 단가 18000과 19000이 나란히 표시된 화면](https://huggingface.co/datasets/eddmpython/eddmpython-media/resolve/main/objects/sha256/03/03eb0c4bce6967cbe6b33081f2bc8a083792e41599b478f2b135aa8d9e387b14.png "한 상품에서 두 값이 바뀌면 내역에는 두 줄이 나옵니다")

기준 열과 값 열을 고른 뒤 `변경 내역 찾기`를 누릅니다. 결과의 `변경`을 누르면 두 파일에 모두 있는 항목 가운데 선택한 값이 달라진 내역만 남습니다. `추가`는 이후 파일에만, `삭제`는 이전 파일에만 있는 항목입니다.

예제로 다시 확인하려면 [비교 도구](#excel-compare)의 `예제로 시작`을 누르고 `변경 내역 찾기`를 누릅니다. 결과에서 `변경`을 고르면 `0012`의 재고와 단가 두 줄이 보입니다. `원본 행`의 `2 / 3`은 이전 파일 2행과 이후 파일 3행을 비교했다는 뜻입니다. 검색칸에 상품코드나 열 이름을 넣으면 그 내용이 들어간 줄을 찾습니다.

## 같아 보이는 값

### 문자 30과 숫자 30은 화면에 같게 보여도 변경으로 구분합니다

![재고의 이전 값과 이후 값은 모두 30이지만 숫자와 문자 표시가 다른 비교 결과 화면](https://huggingface.co/datasets/eddmpython/eddmpython-media/resolve/main/objects/sha256/60/6023fd2431b6bc07ff99c7378974d5771497604ae27ec04f0cdad100a455928f.png "표시된 글자뿐 아니라 셀의 자료형도 비교합니다")

같아 보이는 값이 변경으로 나올 때는 값 아래의 `문자`와 `숫자` 표시를 봅니다. 문자 `30`과 숫자 `30`은 다른 값으로 취급합니다. 직접 확인하려면 [예제 내려받기](#excel-compare)로 받은 이후 파일의 `0012` 재고 칸에 작은따옴표를 붙인 `'30`을 입력하고 다시 저장합니다. Excel에는 30으로 보이지만 문자가 저장됩니다. 이전 파일과 다시 비교하면 재고가 숫자 30에서 문자 30으로 바뀐 내역이 나옵니다.

글꼴이나 배경색, 숫자를 `0000`처럼 보이게 하는 표시 형식은 비교하지 않습니다. 상품코드의 앞자리 0이 실제로 남았는지는 도구의 `읽은 표 확인`에서 확인합니다.

## 앞뒤 공백 처리

### 공백 무시를 켜면 문자 양 끝의 빈칸을 빼고 비교합니다

![문자 앞뒤 공백 무시가 선택된 비교 설정 화면](https://huggingface.co/datasets/eddmpython/eddmpython-media/resolve/main/objects/sha256/b7/b78184f6587ff21a88e79c290418627a2a28d4332288192e93ec23dff77da2c5.png "이 설정은 비교할 값과 기준 값에 함께 적용됩니다")

문자 앞뒤에 붙은 공백을 비교에서 빼려면 `문자 앞뒤 공백 무시`를 켜고 다시 비교합니다. 원본 파일을 고치지는 않으며, 기준 값에도 같은 설정을 적용합니다. 공백을 뺐더니 기준 값이 같아지는 두 행이 있다면 중복 안내가 나옵니다.

## 비교 결과 내려받기

### 결과 파일에 전체 변경 내역과 비교 설정을 함께 담습니다

![전체 결과 xlsx 내려받기 버튼과 다운로드 시작 안내가 표시된 비교 결과 화면](https://huggingface.co/datasets/eddmpython/eddmpython-media/resolve/main/objects/sha256/1a/1a5bd9fa85772f2bdc2458cdab1c1de70bc7e610809a6b4d70ad4d4ebb545797.png "검색으로 화면을 좁혀도 파일에는 전체 내역이 담깁니다")

결과 오른쪽의 `전체 결과 .xlsx 내려받기`를 누르면 `엑셀_변경내역.xlsx`가 브라우저의 다운로드 폴더에 저장됩니다. 브라우저에서 저장 위치를 묻도록 설정했다면 원하는 폴더를 고릅니다. 화면에서 검색하거나 `변경`만 골랐더라도 파일에는 추가와 삭제를 포함한 전체 내역을 담습니다.

파일을 Excel에서 열면 `비교 설정`과 `변경 내역` 시트가 있습니다. `비교 설정`에는 파일과 시트 이름, 제목 행, 기준 열, 비교한 값 열과 공백 설정이 남습니다. `변경 내역`에는 이전 값과 이후 값, 자료형, 양쪽 원본 행 번호가 들어 있습니다. 원본 두 파일은 덮어쓰지 않습니다.

중간에 예제 값을 바꾸거나 공백 설정을 켰다면 `예제로 시작`을 눌러 원래 예제와 설정을 불러옵니다. `변경 내역 찾기`를 누른 뒤 결과 파일을 다시 내려받습니다. 이 파일의 `변경 내역`에서 `0012`를 찾아 재고가 30과 24로, 단가가 18000과 19000으로 들어 있는지 확인해 보세요

예제의 재고와 단가를 확인했다면 같은 방법으로 내 파일의 원본 행을 열어 대조합니다. 검토가 끝나면 도구의 `파일과 결과 지우기`를 눌러 선택한 파일과 비교 결과를 메모리에서 지웁니다.

## 더 해 볼 것

- 수식이 있는 표는 원본 복사본에서 [값만 붙여넣기](https://support.microsoft.com/ko-kr/excel/delete-or-remove-a-formula-in-excel)를 한 뒤 저장합니다. 이 도구는 수식을 계산하거나 저장된 계산 결과를 추측하지 않습니다.
- 병합 셀이 있는 표는 [셀 병합 해제](https://support.microsoft.com/ko-kr/excel/get-started/merge-and-unmerge-cells-in-excel) 후 빈 기준 값을 채웁니다.
- 비교 방식과 시험 입력은 [이 글의 도구 소스](https://github.com/eddmpython/eddmpython/tree/main/blog/posts/007-excel-compare/tool)에서 확인합니다.
