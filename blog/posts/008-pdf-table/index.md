PDF에서 표를 복사했는데 열이 어긋나면 원문과 엑셀을 번갈아 보며 값을 옮겨야 합니다. 페이지가 여러 장이면 같은 제목 행을 지우고 표를 이어 붙이는 작업도 생깁니다.

맨 위 작업대에서 필요한 표를 선택하고, 원문과 값을 맞춘 뒤 출처가 붙은 `PDF_통합표.xlsx`를 저장합니다. 선택한 파일은 브라우저 안에서 처리합니다. 회사 자료는 사용이 허용된 도구인지 먼저 확인해 주세요

## 예제 PDF 열기

### 입고 내역 두 개를 열면 원문과 추출한 표가 나란히 보입니다

![입고 내역 PDF 원문과 상품코드, 품목, 수량, 단가, 금액을 읽은 표](https://huggingface.co/datasets/eddmpython/eddmpython-media/resolve/main/objects/sha256/3d/3dc1b60478124ab8ce2726e43b9b1635476d853b2c2c307466a77e522eaadd41.png "첫 페이지의 표는 5열, 데이터 4행입니다")

[맨 위 작업대](#pdf-table)의 `예제로 둘러보기`를 누릅니다. `입고내역_창고A.pdf`에는 2페이지, `입고내역_창고B.pdf`에는 1페이지가 들어 있습니다. 실제 거래 내역이 아닌 연습용 자료이며, 설치나 가입 없이 열립니다.

왼쪽 문서 목록에서 창고 A의 `1페이지`를 고르면 오른쪽에 상품코드부터 금액까지 5열과 데이터 4행이 보입니다. 첫 상품코드는 `0012`, 품목은 `무선 마우스`입니다. 수량 `24`, 단가 `19,000`, 금액 `456,000`도 원문과 같습니다. 상품코드 앞의 0도 남아 있는지 확인해 보세요

예제 파일을 따로 받으려면 문서 목록에서 파일의 페이지를 고르고 PDF 아래의 `원본 저장`을 누릅니다. 지금 보이는 페이지 한 장이 아니라 선택한 PDF 전체를 내려받습니다. 내 PDF는 작업대로 끌어다 놓거나 `PDF 추가`로 넣습니다. 파일 크기나 개수 제한을 넘으면 화면에 안내가 나옵니다. 암호가 걸린 PDF는 암호를 해제한 사본을 선택합니다.

## 필요한 표 영역

### PDF에서 표를 감싸면 선택한 범위의 글자로 표를 만듭니다

![창고 A의 두 번째 페이지에서 표의 제목과 데이터 네 행을 선택한 영역](https://huggingface.co/datasets/eddmpython/eddmpython-media/resolve/main/objects/sha256/1a/1a2bec2cf608c30d6e3547bac812053bc50ca46155348e79d2d6759c07d98275.png "문서 제목과 표 바깥 합계는 선택 영역에서 뺍니다")

[예제 PDF](#예제-pdf-열기)를 연 작업대에서 창고 A의 `2페이지`를 선택합니다. PDF 위의 `영역`을 누르고, 표의 왼쪽 위에서 오른쪽 아래까지 드래그합니다. `상품코드`가 있는 제목 행과 마지막 상품 `0019`까지 감싸고, 아래쪽 `확인할 합계`는 넣지 않습니다.

오른쪽에 5열과 데이터 4행이 나타나면 표 영역을 잡은 것입니다. 일부 글자가 빠졌다면 선택 테두리의 네 모서리를 끌어 범위를 넓힙니다. 화면이 좁으면 작업대 오른쪽 위의 넓게 보기 버튼을 누르거나 원문과 표 사이의 경계를 끌어 너비를 바꿉니다. 모바일에서는 `PDF 원문`과 `추출한 표` 탭을 오갑니다.

`영역`으로 새 범위를 그리면 기존 표를 바꾸는 대신 표를 하나 더 만듭니다. 같은 표를 두 번 잡았다면 아래 `통합할 표`에서 불필요한 표의 삭제 버튼을 누릅니다. 목록에는 이번에 내보낼 표만 남겨 주세요

## 어긋난 열 경계

### 구분선을 움직여 상품코드와 품목을 서로 다른 열에 넣습니다

![상품코드와 품목 사이 구분선을 오른쪽으로 옮겨 품목 글자와 겹친 PDF 화면](https://huggingface.co/datasets/eddmpython/eddmpython-media/resolve/main/objects/sha256/07/076d64a7cc354f091bb2ad88338a133936333c538e523c32ef0ee39e29e8a33f.png "구분선이 글자 위를 지나면 열 경계를 다시 맞춥니다")

[작업대](#pdf-table)에서 창고 A의 `1페이지`를 선택합니다. PDF 표 안의 세로 구분선은 오른쪽 표에서 열을 나눌 위치입니다. 상품코드와 품목 사이 선을 오른쪽으로 끌어 보면 품목 글자와 겹칩니다. 선을 상품코드와 품목 사이의 빈 곳으로 옮겨 `0012`와 `무선 마우스`가 각각 한 칸에 들어오게 맞춥니다.

구분선이 부족하면 `열 나누기`를 누르고 선을 넣을 위치를 클릭합니다. 필요 없는 선은 클릭한 뒤 `Delete`로 지웁니다. 선택한 구분선은 방향키로 조금씩 움직일 수도 있습니다. 열 제목이 잘못 읽혔다면 오른쪽 표 맨 위의 열 이름을 직접 고칩니다.

경계를 바꾸면 그 표의 셀 수정값과 숫자 열 설정 등이 초기화됩니다. 그래서 경계를 먼저 맞춘 뒤 값을 검토합니다. 첫 행이 `0012 / 무선 마우스 / 24 / 19,000 / 456,000`인지 확인합니다.

## 셀 원문 대조

### 셀을 누르면 PDF 위치와 수정 전 값을 함께 확인할 수 있습니다

![품목 셀의 원문 무선 마우스와 직접 수정한 무선 마우스 검토가 나란히 표시된 화면](https://huggingface.co/datasets/eddmpython/eddmpython-media/resolve/main/objects/sha256/ac/ac6607f39c130900a2339dcb3a401fae4b5d40e879034fb79fca95be789a764d.png "직접 고친 값 옆에도 PDF에서 읽은 원문이 남습니다")

[작업대](#pdf-table)에서 창고 A의 `1페이지`를 고르고, 오른쪽 표의 `무선 마우스` 셀을 누릅니다. PDF에는 그 셀에 해당하는 범위가 표시되고, 표 아래에는 파일명과 페이지, 원문 값이 나타납니다.

값을 고치려면 셀을 두 번 누르거나 셀에 초점을 둔 채 `F2`를 누릅니다. 수정 동작을 시험하려면 `무선 마우스 검토`를 입력하고 `Enter`를 눌러 보세요

표에는 수정한 값이 들어가지만 아래 `원문`에는 `무선 마우스`가 남습니다. `수정`에는 방금 입력한 문장이 보입니다. 시험이 끝났으면 `되돌리기`로 원래 값을 복구합니다. 실제 검토에서는 PDF와 값이 맞는지 대조한 뒤 `원문 확인`을 누릅니다. 확인 표시는 사람이 확인했다는 기록이며 자동으로 정답을 판정한 결과가 아닙니다.

## 금액 합계 검증

### 숫자로 읽을 열을 고르고 PDF에 적힌 합계와 맞춰 봅니다

![금액 열의 읽은 합계와 기준 합계가 모두 1723000으로 일치하는 화면](https://huggingface.co/datasets/eddmpython/eddmpython-media/resolve/main/objects/sha256/e4/e4eab49322ca2aaa93a758c921c4d3837ae236f736d25480e6c4648505868a30.png "창고 A의 첫 페이지 금액 합계는 1,723,000원입니다")

[작업대](#pdf-table)의 창고 A `1페이지`에서 `금액 (원)` 열 이름 옆 `123`을 누릅니다. 금액 열을 숫자로 읽도록 지정하면 표 아래에 합계가 나타납니다. `기준 합계 입력`에 PDF의 `확인할 합계`에 적힌 `1,723,000`을 넣습니다. 예제 값을 바꾸지 않았다면 `합계 일치`가 보입니다.

합계가 같으면 모든 값도 맞을까요? 두 칸의 오류가 서로 상쇄되면 합계는 같을 수 있습니다. 합계 검증은 틀린 표를 찾는 보조 수단이므로, [셀 원문 대조](#셀-원문-대조)도 함께 합니다. `합계 불일치`가 보이면 빠진 행, 잘못 읽은 금액, 선택 영역에 섞인 합계 행부터 원문과 비교합니다.

`123`을 켠 열에서 숫자로 읽은 값은 엑셀에도 숫자로 저장됩니다. 상품코드처럼 앞자리 0이 중요한 열에는 켜지 않습니다. 숫자로 읽을 수 없는 칸이 있으면 `숫자 확인` 항목이 생기며, 기준 합계는 현재 선택한 표에만 적용됩니다. 다른 페이지에서는 그 페이지의 합계를 따로 넣어 확인합니다.

## 여러 페이지의 표 모으기

### 아직 표를 추출하지 않은 페이지에 현재 표의 영역과 열 설정을 적용합니다

![여러 페이지의 표가 통합할 표 목록에 모인 PDF 작업대](https://huggingface.co/datasets/eddmpython/eddmpython-media/resolve/main/objects/sha256/a7/a78046d7058234e6f3fdbea81ddb568610714e2a6faef28fe0fcd12c1bec5dae.png "목록에 남긴 표를 순서대로 엑셀에 모읍니다")

[작업대](#pdf-table)에서 창고 A의 `1페이지` 표를 선택하고, 아래쪽 `다른 페이지에도 적용`을 누릅니다. 현재 PDF뿐 아니라 열어 둔 다른 PDF에서도 표가 없는 페이지를 찾아 같은 위치와 열 설정을 적용합니다. 이미 표를 만든 페이지는 덮어쓰지 않습니다.

예제를 그대로 따라왔다면 창고 A의 두 페이지와 창고 B의 한 페이지, 총 3개 표가 목록에 모이고 내보내기 버튼에는 `12행`이 표시됩니다. 목록에서 각 표를 눌러 상품코드와 첫 행을 원문에 맞춰 봅니다. 양식이 달라 표 위치가 바뀐 페이지는 영역을 다시 잡아야 합니다.

`통합할 표`의 손잡이를 끌면 내보낼 순서가 바뀝니다. 작은 화면에서는 각 표의 좌우 화살표로도 옮길 수 있습니다. 이름이 같은 열끼리 모으므로 `금액`과 `금액 (원)`처럼 같은 뜻을 다르게 읽은 열은 제목을 맞춘 뒤 저장합니다. 단위나 뜻이 다른 열까지 이름만 같게 만들지는 않습니다.

## 엑셀로 저장

### 통합한 값과 원문 근거를 한 파일에 담습니다

![3개 표 12행을 엑셀로 내보내는 버튼과 원문을 함께 표시한 작업대](https://huggingface.co/datasets/eddmpython/eddmpython-media/resolve/main/objects/sha256/e3/e3604e34c9e2644d291e907850bc53b62d07e63be93016d445e7d563e0082712.png "현재 보고 있는 한 표가 아니라 목록의 모든 표를 내보냅니다")

[작업대](#pdf-table) 오른쪽 위의 `엑셀로 내보내기`를 누릅니다. `PDF_통합표.xlsx`가 브라우저의 다운로드 폴더에 저장됩니다. 저장 위치를 묻는 브라우저에서는 원하는 폴더를 고릅니다. `확인할 칸`은 의심되는 칸만 보여 주는 필터입니다. 필터를 켜도 엑셀에는 `통합할 표` 목록의 모든 표를 저장하며, 행 번호를 눌러 제외한 행은 빠집니다.

파일을 Excel에서 열면 `통합 표`, `원문 근거`, `검토 항목` 시트가 있습니다. `통합 표`에는 추출한 값과 원본 파일명, 페이지가 들어갑니다. `원문 근거`에는 칸마다 PDF에서 읽은 값, 수정한 값, 확인 상태와 페이지 안의 위치가 남습니다. `검토 항목`에는 아직 확인하지 않은 인식 문제나 합계 불일치를 모읍니다.

예제의 `통합 표`에서 상품코드 `0012`를 찾아 앞자리 0과 금액 `456,000`을 확인합니다. 같은 행의 원본 파일은 `입고내역_창고A.pdf`, 페이지는 `1`이어야 합니다. `원문 근거` 시트에서도 같은 파일과 페이지를 찾아 상품코드와 금액이 일치하는지 봅니다. 실무 자료도 같은 방식으로 출처까지 대조한 뒤 사용합니다.

## 추출 설정 재사용

### 표 위치와 열 설정을 파일로 저장해 다음 문서에 적용합니다

![현재 표의 추출 설정을 저장하고 다시 여는 작업대 버튼](https://huggingface.co/datasets/eddmpython/eddmpython-media/resolve/main/objects/sha256/4b/4bb942d579efe0e60453231c046f39773875a54e6aba2138e8eeaf3df9d25b88.png "설정 파일에는 PDF 원문이나 수정한 셀 값이 들어가지 않습니다")

[작업대](#pdf-table)에서 재사용할 표를 선택하고 `설정 저장`을 누르면 `PDF_추출설정.json`을 받습니다. JSON은 설정을 보관하는 파일 형식이며, 직접 열어 고칠 필요는 없습니다. 표의 위치, 열 구분선, 제목 행 수, 열 이름과 숫자 열 선택을 담습니다. 수정한 값과 확인 기록, 제외한 행, 기준 합계는 저장하지 않습니다.

직접 적용해 보려면 창고 A의 `1페이지`에서 설정을 저장한 뒤 `PDF 추가`로 [원본 저장으로 받은](#예제-pdf-열기) `입고내역_창고A.pdf`를 다시 넣습니다. 새로 추가된 파일의 `1페이지`를 고르고 `설정 열기`에서 `PDF_추출설정.json`을 선택합니다. 표 위치와 5개 열이 다시 잡히는지 확인합니다. 같은 파일을 다시 넣었으므로 저장 결과에 중복으로 들어가지 않게 추가한 표는 목록에서 지웁니다.

다음 달 자료도 같은 위치에 같은 열이 있을 때 이 설정을 씁니다. 페이지마다 글자를 읽어 행을 다시 나누므로 행 수는 이전 자료와 같지 않아도 됩니다. 다만 표 위치나 열 너비가 달라졌다면 구분선을 조절한 뒤 설정을 새로 저장합니다. 새로고침하면 문서와 편집 내용이 사라지므로 결과 엑셀과 설정 파일을 먼저 받아 둡니다.

## 스캔 PDF의 글자 인식

### 사진으로 들어 있는 표는 글자를 읽은 뒤 원문과 다시 맞춥니다

![스캔한 입고 내역에서 글자를 인식해 상품코드와 금액을 읽은 작업대](https://huggingface.co/datasets/eddmpython/eddmpython-media/resolve/main/objects/sha256/b8/b805f0132362a7578a1ee49423df7a4f3663e864ac0b503a898b56c1bdcfabc5.png "스캔본에서 읽은 표의 빈 칸과 잘못 읽은 글자를 원문과 대조합니다")

PDF가 보이는데 `텍스트 없는 페이지`라고 나오면 페이지가 사진으로 들어 있을 수 있습니다. [작업대](#pdf-table) 아래의 `스캔본 예제 열기`를 누르면 글자 인식을 연습할 수 있습니다. 현재 문서와 편집 내용을 바꾸는 동작이므로 필요한 결과를 먼저 저장하고, 교체 안내를 확인합니다. 스캔 예제도 `원본 저장`으로 내려받을 수 있습니다.

PDF 아래 `스캔본 글자 인식`을 누릅니다. 한글과 영문 인식에 필요한 파일을 이 사이트에서 읽은 뒤 브라우저 안에서 처리하며, PDF를 서버로 보내지 않습니다. 진행 표시가 사라지고 `글자 인식 결과`가 보이면 표 영역을 원문에 맞춥니다.

예제에서 상품코드 `0012`와 금액 `456,000`을 먼저 대조합니다. 글자 인식은 빈 칸을 만들거나 비슷한 글자를 바꿔 읽을 수 있습니다. `확인할 칸`은 발견된 의심 항목을 모아 보여 줄 뿐, 나머지 칸의 정확성까지 보장하지 않습니다. 빠진 수량이나 잘못 읽은 글자는 [셀 수정 방법](#셀-원문-대조)으로 고치고 원문 확인 표시를 남깁니다.

스캔본의 표를 고쳤으면 [엑셀로 저장](#엑셀로-저장)의 방법으로 결과 파일을 새로 내려받습니다. 새 파일에서 값과 원본 파일명, 페이지를 함께 대조합니다. PDF 원문과 대조해 고친 값이 저장됐는지 확인해 보세요

## 더 해 볼 것

- Python으로 직접 만들려면 [Codaro PDF 표 추출 실습](https://eddmpython.github.io/codaro/learn/lesson/pdf/04_%ED%91%9C%EC%B6%94%EC%B6%9C/)에서 같은 예제 PDF 두 개를 읽고 원본 위치와 함께 엑셀로 저장해 봅니다. Local 실행 방법과 PDF 파일, Python 코드를 제공하며, 이미지 PDF는 OCR 검토 대상으로 구분합니다.
- 글자 인식을 중단하려면 [작업대](#pdf-table)의 `취소`를 누릅니다. 다시 읽으려면 `스캔본 글자 인식`을 누릅니다.
- 반복 제목이나 합계 행을 빼려면 [작업대](#pdf-table)의 표 왼쪽 행 번호를 누릅니다. 다시 누르면 결과에 포함됩니다.
- 쪼개진 셀을 합치려면 [작업대](#pdf-table)에서 첫 셀을 누르고 `Shift`를 누른 채 마지막 셀을 선택한 뒤 `셀 병합`을 누릅니다. 직접 수정한 값이 있다면 초기화 안내를 먼저 확인합니다.
- 숫자 검토를 먼저 끝냈다면 [엑셀 비교 도구](/blog/excel-compare)로 이전 자료와 값이 달라진 항목을 찾아볼 수 있습니다.
