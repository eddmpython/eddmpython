설치는 나중에 해도 됩니다.

파이썬 설치 방법을 검색하면 버전이 어떻고 `PATH` 를 잡으라 하고 처음 보는 말이 한꺼번에 나옵니다. 저도 여기서 한 번 접었던 적이 있죠. 그런데 첫 코드를 돌려 보는 데는 설치가 필요 없습니다. 브라우저만 있으면 됩니다.

## 첫 코드는 여섯 줄이면 됩니다

![짧은 Python 명령이 붕어빵 주문 영수증 결과로 바뀌는 실행 흐름](https://huggingface.co/datasets/eddmpython/eddmpython-media/resolve/main/objects/sha256/7d/7dd30cfe6faea2d684950be94309e088999242e29ca6514ba2fddf98ad824c15.png "왼쪽에 적은 수량과 가격이 오른쪽 영수증 한 줄로 바뀝니다")

붕어빵 가게에서 팥 두 개와 슈크림 한 개를 한 개 `1000` 원에 팔았다고 하겠습니다. 엑셀이라면 칸에 `=(2+1)*1000` 을 적으면 끝입니다. 그럼 파이썬에서는 뭘 적어야 할까요?

결과부터 보면 `붕어빵 3개, 3,000원` 한 줄이 화면에 찍힙니다. 이걸 만드는 코드가 아래입니다.

#### 예시 코드: 수량과 가격을 계산해 한 문장으로 출력하기

```python
red_bean = 2
custard = 1
price = 1000

count = red_bean + custard
total = count * price

print(f"붕어빵 {count}개, {total:,}원")
```

한 줄씩 보겠습니다.

red_bean = 2 팥 붕어빵 개수인 `2` 에 `red_bean` 이라는 이름을 붙입니다. 여기 등호를 수학의 같다로 읽으면 다음 줄에서 막힙니다. 오른쪽 값에 왼쪽 이름을 붙이라는 지시입니다.

custard = 1 슈크림 개수인 `1` 에도 이름을 붙입니다.

price = 1000 한 개 가격입니다. 나중에 이 숫자만 바꾸면 전체 금액이 따라 바뀝니다.

count = red_bean + custard 오른쪽을 먼저 계산하고 그 결과에 `count` 라는 이름을 붙입니다.

total = count \* price 위에서 만든 `count` 를 가져다 씁니다. 그래서 순서가 중요합니다. `count` 를 만들기 전에 이 줄이 오면 그런 이름이 없다는 오류가 납니다.

print(...) 괄호 안의 값을 화면으로 꺼냅니다. 따옴표 앞의 `f` 는 중괄호 안을 값으로 바꿔 끼우라는 표시이고, `{total:,}` 의 콜론 뒤 쉼표가 천 단위마다 쉼표를 넣습니다.

빈 줄을 빼면 명령 여섯 줄입니다. 값을 적고 더하고 곱하면 답이 나오니 시작이 싱거울 정도죠!

## 지금 고쳐서 실행해 봅니다

![브라우저 코드 입력칸의 붕어빵 수량이 실행 버튼을 거쳐 새 영수증 결과로 바뀌는 모습](https://huggingface.co/datasets/eddmpython/eddmpython-media/resolve/main/objects/sha256/57/57a319f7b8b14b5a6271e0ab6f27f2607921bd5e5b669861ba4266a32dd5fc7e.png "수량을 고치고 실행을 누르면 아래 결과가 새로 찍힙니다")

아래 칸에 앞에서 본 붕어빵 코드가 그대로 들어 있습니다. 실행 버튼을 누르면 브라우저 안에서 바로 돌아갑니다. 가입도 설치도 필요 없습니다.

https://eddmpython.com/codaro/run/?example=python-bungeoppang-order

`red_bean = 2` 를 `red_bean = 5` 로 고치고 실행을 눌러 보시기 바랍니다. 결과가 `붕어빵 6개, 6,000원` 으로 바뀌면 값을 적고 계산하고 화면에 내보내는 세 동작을 직접 돌린 것입니다.

그럼 마지막 줄을 지우고 한번 더 실행해 보시겠어요?

아무것도 안 나오죠? 계산은 그대로 됐습니다. 값이 이름에만 담기고 밖으로 나오지 않았을 뿐입니다. 저도 처음엔 코드가 틀린 줄 알고 세 번이나 다시 쳤습니다. 결과가 안 보인다고 하는 경우의 상당수가 이것으로 보입니다.

#### 실패 예시: 숫자를 바꾼 뒤 실행되지 않을 때 확인할 곳

- `red_bean = 다섯` 처럼 따옴표 없는 글자를 넣으면 파이썬이 그것을 이름으로 읽어 그런 이름이 없다는 오류를 냅니다.
- `red_bean = 5` 에서 등호 왼쪽 이름을 지우면 값을 어디에 붙일지 알 수 없어 멈춥니다.
- 줄 앞에 빈칸을 넣으면 들여쓰기로 읽혀 앞 줄의 묶음에 들어가려다 오류가 납니다.

## 앞으로 배울 문법은 많지 않습니다

방금 여섯 줄에서 이미 두 가지를 썼습니다. 값에 이름을 붙이는 것과 그 이름을 계산에 쓰는 것이죠. 회사 일을 자동화하는 데 필요한 문법은 여기에 몇 가지만 더하면 됩니다.

값을 여러 개 담는 방법 거래처 300곳을 이름 300개로 만들 수는 없습니다.

조건을 나누는 방법 금액이 `100000` 을 넘으면 표시하고 아니면 넘어갑니다.

같은 일을 되풀이하는 방법 300건에 같은 처리를 적용합니다.

이름을 붙여 다시 쓰는 방법 같은 계산을 여러 곳에서 씁니다.

넷입니다. 생각보다 적죠? 개인적으로는 우리가 이 넷만 알아도 회사에서 마주치는 엑셀 일의 대부분이 손에 잡힌다고 봅니다. 남은 것은 남이 만들어 둔 묶음을 불러 쓰는 일인데, 그건 문법이 아니라 사용법이죠.

다만 방금 누른 것은 실행 버튼 하나뿐입니다. 여섯 줄보다 긴 코드를 이 칸에 어떻게 쓰고, 어디에 저장하고, 다음에 다시 어떻게 여는지는 아직 보지 않았습니다.
