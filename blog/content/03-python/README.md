# 파이썬 도구

**이 폴더가 파이썬 도구 주제를 소유한다.** 링크를 QR로 바꾸는 것처럼 작은 도구를 화면에서
바로 써 보고, 같은 것을 파이썬 코드로 만드는 법을 다룬다.

## 여기 오는 글

- 화면에서 바로 쓰는 도구와 그것을 파이썬으로 옮기는 법
- 외부 라이브러리를 설치해 파일을 만드는 법
- 값을 바꾸면 결과가 어떻게 달라지는지 확인하는 법

AI 에게 일을 시키는 이야기는 `../01-ai-workflow/` 가, 글쓰기는 `../02-writing/` 가 소유한다.

## 이 폴더에 규칙 문서를 만들지 않는다

`../../README.md` 의 규칙이 그대로 적용된다. 기계가 강제하는 계약은
`skills/specs/operation/blogPublishing.md` 다. 글이 품는 도구의 정본은 `blog/embeds/tools.json`
과 사이트의 도구 레지스트리다.
