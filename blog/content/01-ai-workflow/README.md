# AI와 일하기

**이 폴더가 AI 작업 환경 주제를 소유한다.** AI 코딩 도구가 저장소의 명령과 경계를 스스로
조사하고 문서로 남기게 만드는 법을 다룬다.

## 여기 오는 글

- AI 에게 저장소를 조사시키고 지침 파일을 쓰게 하는 법
- 작업 환경, 실행 명령, 권한 경계, 완료 증거를 정하는 법
- 새 대화에서도 같은 결과가 나오는지 검증하는 법

글을 어떻게 쓰는가는 `../02-writing/` 이 소유한다. 도구에게 일을 시키는 글과 글 자체를 다루는
글은 독자가 다르다.

## 이 폴더에 규칙 문서를 만들지 않는다

`../../README.md` 의 규칙이 그대로 적용된다. 판단과 작법은 비공개 형제 저장소의
`../eddmpython-course/memory/rules/blogWriter.md`, 기계가 강제하는 계약은
`skills/specs/operation/blogPublishing.md` 다.
