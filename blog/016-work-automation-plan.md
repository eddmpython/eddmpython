업무자동화 기획서 없이 코딩부터 시작하면 `Excel 정리해 줘` 같은 한 문장이 수십 가지 해석으로
갈립니다. 어떤 파일을 읽고 어떤 행을 확인하며 무엇이 맞아야 성공인지 없으면 사람과 AI 모두 결과를
추측하게 됩니다.

이 글에서는 부서별 지출내역 취합을 한 장으로 정리합니다. 입력, 처리, 판단, 출력, 검증을 실제 파일과
숫자로 채우고, 민감한 원본 대신 아홉 행의 합성 자료로 첫 실행을 시작할 수 있게 만듭니다.

## 반복업무 하나만 고릅니다

### 횟수와 시간 및 입력 파일과 결과 파일을 한 줄로 말할 수 있는 일을 선택합니다

![반복 횟수와 소요 시간 및 입력과 출력이 분명한 업무 하나가 첫 자동화 대상으로 선택되는 모습](https://huggingface.co/datasets/eddmpython/eddmpython-media/resolve/main/objects/sha256/d0/d07c6bf96eec2dded6234b29ba6518206da50b8cd8c919414c4a67fcaa0eacd8.png "한 번에 여러 업무를 묶지 않고 시작과 끝을 파일로 확인할 수 있는 일 하나를 고릅니다")

첫 대상은 자주 반복되고 규칙이 비교적 일정한 일이 좋습니다. `매주 금요일 부서별 Excel 세 개를 열어
한 파일로 합치고 합계가 맞는지 확인한다`처럼 횟수와 입력 및 결과를 한 문장에 넣습니다. 월 1회 5분짜리
일보다 매주 2시간이 걸리는 일이 자동화 효과를 확인하기 쉽습니다.

`보고 업무 자동화`처럼 범위가 넓은 이름은 피합니다. 자료 수집, 표 정리, 메일 발송이 모두 들어갈 수
있기 때문입니다. 첫 실험은 `input 폴더의 xlsx 세 개를 output의 결과 파일 하나로 만든다`처럼 파일
경계가 보이는 크기로 줄입니다.

#### 확인 목록

- 한 달에 몇 번 반복하는지 숫자로 적습니다.
- 한 번에 몇 분이 걸리는지 기록합니다.
- 시작할 때 받는 파일이나 화면을 적습니다.
- 끝났을 때 생기는 파일이나 전달물을 적습니다.
- 한 문장에 서로 다른 업무가 두 개 이상이면 하나를 뺍니다.

#### 예시

```text
매주 1회, 약 120분
input의 부서별 지출 Excel 3개를 읽음
output에 검증된 지출 결과 Excel 1개를 만듦
```

## 실제 자료 대신 합성 표를 만듭니다

### 열 이름과 값의 종류는 닮고 사람과 회사 정보는 없는 5행에서 20행을 준비합니다

![실제 지출 표의 민감한 열이 가려지고 같은 열 구조를 가진 아홉 행의 합성 표로 바뀌는 모습](https://huggingface.co/datasets/eddmpython/eddmpython-media/resolve/main/objects/sha256/42/426d9c1aba76b86cfe6ede599e4ab6c3519ca3780855b0e8baa955a461472e3e.png "코드가 알아야 할 열과 값의 종류는 보존하고 이름과 계좌 및 실제 거래 내용은 가져오지 않습니다")

실제 Excel 파일을 AI에 올리거나 공개 저장소에 넣으면 이름, 거래처, 계좌, 계약 금액이 노출될 수
있습니다. 첫 실험에는 같은 열 이름과 자료형만 가진 합성 자료를 사용합니다. `김서준` 대신 `담당자A`,
실제 거래처 대신 `거래처1`처럼 업무와 무관한 값으로 바꿉니다.

정상 행만 만들면 오류 처리를 시험할 수 없습니다. 아홉 행 중 하나는 부서를 비우고, 하나는 금액에
`금액미정`을 넣으며, 하나는 확인 기준인 `100000`원과 정확히 같게 만듭니다. 코드가 정상값과 빈값 및
경계값을 모두 다루는지 작은 표에서 확인합니다.

#### 설명 목록

```text
남길 것: 열 이름, 날짜 모양, 숫자와 문자 종류, 빈값 위치, 경계값
바꿀 것: 사람 이름, 회사 이름, 계좌, 주소, 실제 계약과 거래 내용
권장 크기: 5행에서 20행
반드시 포함: 정상값, 빈값, 잘못된 값, 기준과 같은 값
```

## 다섯 칸에 실제 동작을 적습니다

### 입력과 처리 및 판단과 출력과 검증을 파일 이름과 조건 및 숫자로 채웁니다

![입력과 처리와 판단 및 출력과 검증 다섯 칸에 파일과 코드 동작 및 결과 숫자가 차례로 채워진 모습](https://huggingface.co/datasets/eddmpython/eddmpython-media/resolve/main/objects/sha256/77/7777233232ac7345b9c4124deaf3db79b9ad7dc4ceddab60cd442fdb56635a83.png "각 칸을 읽으면 코드가 무엇을 읽고 바꾸며 어떤 결과를 확인해야 하는지 알 수 있습니다")

기획서의 중심은 입력, 처리, 판단, 출력, 검증 다섯 칸입니다. 입력에는 `Excel 자료`가 아니라
`input/*.xlsx, 열 5개`라고 적습니다. 처리에는 `정리` 대신 `세 파일의 행을 세로로 합치고 원본파일
열을 추가`라고 적습니다.

판단에는 사람이 하던 조건을 그대로 씁니다. 금액이 `100000` 이상이거나 부서가 비었거나 금액이
숫자가 아니면 확인필요로 보냅니다. 출력에는 결과 파일과 시트 네 개를, 검증에는 입력 파일 3개와 통합
9행 및 합계 597000원처럼 실행 뒤 비교할 숫자를 적습니다.

#### 예시

```text
입력: input/*.xlsx 3개, 일자/부서/항목/금액/비고 열
처리: 필수 열 검사, 행 합치기, 원본파일 열 추가, 금액 숫자 변환
판단: 100000원 이상, 부서 누락, 숫자 아닌 금액은 확인필요
출력: output/expense_result.xlsx, 시트 4개
검증: 입력 3개, 통합 9행, 확인필요 4행, 합계 597000원
```

## 예외는 조건과 행동을 함께 적습니다

### 파일 없음과 열 누락 및 잘못된 금액마다 멈출지 기록할지 결정합니다

![파일 없음과 열 누락 및 잘못된 금액과 열린 결과 파일이 각각 정해진 오류 행동으로 연결된 모습](https://huggingface.co/datasets/eddmpython/eddmpython-media/resolve/main/objects/sha256/7e/7e7534cf044b37b90f1b544d871b66340be8f339d55f9ce6283fb9e44a5abf6a.png "예외 이름만 모으지 않고 어떤 메시지를 남기고 실행을 계속할지 또는 멈출지를 정합니다")

예외 목록에 `오류 처리`라고만 적으면 코드를 만들 수 없습니다. 어떤 입력에서 문제가 생기고 그때 무엇을
해야 하는지 한 줄에 함께 씁니다. 입력 파일이 0개이거나 필수 열이 빠지면 결과를 만들지 않고 파일
이름이 있는 오류로 멈춥니다.

부서가 비거나 금액이 숫자가 아닌 행은 전체 실행을 멈출 필요가 없습니다. 해당 행을
`03_확인필요`에 원문과 이유를 넣고 나머지 행은 처리합니다. 결과 Excel을 사용자가 열어 둬 저장할 수
없다면 파일을 닫으라는 메시지를 보여 주고 기존 결과를 손상하지 않습니다.

#### 예시

| 예외 | 코드가 할 행동 |
| --- | --- |
| input에 xlsx가 0개 | 폴더 경로를 적고 중단 |
| 필수 열 누락 | 파일 이름과 빠진 열을 적고 중단 |
| 부서 빈칸 | 확인필요 시트에 이유를 남기고 계속 |
| 금액이 문자 | 원문을 보존하고 확인필요로 보내기 |
| 결과 파일이 열려 있음 | 파일을 닫으라는 오류를 보여 주고 중단 |

## 완료 조건은 눈이 아니라 숫자로 씁니다

### 파일 존재와 시트 이름 및 건수와 금액과 재실행을 PASS 또는 FAIL로 판단합니다

![결과 Excel의 파일과 시트 및 행 수와 금액과 재실행 항목이 기대값과 비교되어 PASS로 표시되는 모습](https://huggingface.co/datasets/eddmpython/eddmpython-media/resolve/main/objects/sha256/40/40eb8266fc1d9f19fa63823a08aa324e92423263d2afebd3a3addcca7fb2728e.png "완료했다는 느낌 대신 실행 뒤 자동으로 비교할 수 있는 값으로 성공 조건을 정합니다")

`보기 좋게 정리`는 사람마다 판단이 다릅니다. `output/expense_result.xlsx가 있고 시트 이름 네 개가
정확히 일치`처럼 화면이나 코드에서 확인할 수 있는 문장으로 바꿉니다. 건수와 금액도 입력과 출력의
차이가 0이라고 적습니다.

재실행 조건도 처음부터 넣습니다. 같은 입력으로 두 번 실행했을 때 통합 행이 9개로 유지되고 원본
Excel의 내용이 바뀌지 않아야 합니다. 완료 조건은 마지막 검사만 위한 문장이 아니라 코드를 어느
방향으로 작성할지 정하는 기준입니다.

#### 확인 목록

- 결과 파일 경로가 존재합니다.
- 시트 이름 네 개와 순서가 약속과 같습니다.
- 입력과 통합내역의 행 수 차이는 0입니다.
- 입력과 통합내역의 계산 가능한 금액 차이는 0원입니다.
- 같은 입력으로 두 번 실행한 통합내역이 같습니다.
- 변경된 원본 입력 파일은 0개입니다.

## 한 장 기획서를 그대로 채웁니다

### 빈 템플릿과 지출내역 예시를 나란히 두고 첫 실행 명령까지 적습니다

![빈 업무자동화 기획서의 항목이 지출내역 파일과 처리 규칙 및 검증 숫자로 채워져 실행 준비 상태가 되는 모습](https://huggingface.co/datasets/eddmpython/eddmpython-media/resolve/main/objects/sha256/38/38c135b7076e211c171f871e2da74620bb7031e96915160d9d47e487e8c08eba.png "목적부터 첫 실행 명령까지 한 화면에 있으면 사람과 AI가 같은 작업 범위를 읽을 수 있습니다")

아래 템플릿을 복사해 대괄호 안을 실제 값으로 바꿉니다. 파일 경로와 열 이름은 복사해 쓸 수 있을 만큼
정확히 적고, 판단 조건에는 `이상`, `초과`, `같음`을 구분합니다. 수정 금지 대상에는 원본 폴더와 기존
결과물을 적습니다.

지출내역 예시는 구현자가 추가 질문 없이 합성 자료를 만들고 첫 명령을 실행할 수 있는 수준입니다.
기획서를 AI에 줄 때도 저장소 링크와 함께 이 내용을 제공하고, 먼저 파일 목록과 실행 계획을 말한 뒤
작은 합성 자료에서 검사하도록 요청합니다.

#### 예시

```text
[업무자동화 한 장 기획서]

업무 이름: [반복업무 하나]
반복 횟수와 시간: [주 1회, 120분]
목적: [무엇을 몇 분 안에 끝낼지]

입력 파일: [정확한 폴더와 파일 모양]
필수 열 또는 필드: [이름과 자료형]
처리 순서: [읽기, 검사, 변환, 합치기, 저장]
판단 조건: [조건식과 보낼 위치]
예외와 행동: [문제 입력과 중단 또는 기록]
출력 파일: [정확한 경로와 파일 이름]
출력 구성: [시트, 열, 보고서 항목]
검증 숫자: [건수, 합계, 차이]
재실행 조건: [두 번 실행해도 같아야 할 값]
수정 금지: [원본과 건드리면 안 되는 폴더]
합성 자료: [5행에서 20행, 포함할 오류와 경계값]
첫 실행 명령: [터미널에서 복사할 한 줄]
완료 조건: [PASS 항목 목록]
```

#### 예시

```text
업무 이름: 부서별 지출내역 자동 취합
반복 횟수와 시간: 매주 1회, 120분
목적: 수작업 120분을 실행과 검증 10분 안으로 줄이기
입력 파일: input/*.xlsx 3개
필수 열: 일자, 부서, 항목, 금액, 비고
판단 조건: 100000원 이상 또는 부서 누락 또는 숫자 아닌 금액은 확인필요
출력 파일: output/expense_result.xlsx
출력 구성: 통합내역, 부서별요약, 확인필요, 검증결과
검증 숫자: 3개, 9행, 확인필요 4행, 합계 597000원, 차이 0
재실행 조건: 두 번 실행한 통합내역이 같고 원본 변경 0개
수정 금지: input의 원본 Excel
합성 자료: 9행, 빈 부서 1행, 문자 금액 1행, 100000원 이상 2행
첫 실행 명령: uv run python src/main.py
완료 조건: 검증 6개 PASS
```
