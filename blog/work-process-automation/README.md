흐름의 정본은 [원장.md](원장.md)다. 글을 쓰거나 순서를 바꾸기 전에 원장의 제목 사슬을 먼저 고친다.

## 이 폴더의 규칙

- 글 파일만 `NNN-kebab.md`다. `NNN`은 저장소 전체의 발행 순번이며 공개 읽기 순서가 아니다.
- 공개 URL은 frontmatter `slug`다. `/blog/{slug}`. 카테고리를 URL에 넣지 않는다.
- 목록 순서와 목록에 올릴지는 `blog/order.json`이 정한다.
- 다시 쓰기 전인 글은 파일과 URL을 지우지 않고 `archived`로 내린다.
