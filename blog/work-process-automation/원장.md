# 업무프로세스자동화 원장

이 파일의 일은 글 제목과 절 제목을 열거해 앞이 다음 질문을 만드는지 보는 것이다.
본문 초안, 시연 카탈로그, 게이트 점수는 여기 쌓지 않는다.

확정은 운영자만 찍는다. 에이전트는 제목 초안을 올리고 순서는 운영자가 정한다.
한 번에 한 편만 작업중으로 둔다.

읽는 법. 각 줄은 `제목 → 이 글이 남기는 다음 질문`이다.
제목 순서를 바꿔도 사슬이 성립하면 나열이다. 그 줄은 빼거나 자리를 옮긴다.

공개 URL은 `/blog/{slug}`다. 파일 순번 `NNN`은 미디어 키일 뿐 목록 순서가 아니다.

## 이 묶음이 답하는 질문

회사 반복 업무를 자동화하려면 무엇부터 보고, 여러 방법 중에 왜 파이썬으로 시작해, 지금 무엇을 누르면 되나?

1번이 선택을 끝낸다. 2번이 그 손으로 첫 실행만 시킨다.
그다음부터는 내 컴퓨터의 파일, 엑셀 장면, 엑셀 밖 문서, AI로 맡기기 순이다.

문법 단독 글과 설치 복구 글은 척추에 두지 않는다. 실습 글 안에서 막힐 때 연다.

## 1번 6~7절에만 필요한 확인

- 빠른 채우기는 이미 있는 칸의 무늬만 복제한다. 국세청을 못 부른다.
- 매크로 기록기는 변수와 제어문을 기록하지 못한다. Microsoft 지원 문서.
- 손으로 쓴 VBA는 `MSXML2.XMLHTTP`로 국세청을 칠 수 있다.
- Microsoft Python in Excel은 네트워크 자체가 없다. xlwings Lite는 CORS. 글의 그 조회를 Lite에서 쳐 보고 죽는 화면을 확인한다.
