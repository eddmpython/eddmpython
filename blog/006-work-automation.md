업무자동화란 무엇인가를 알아보려고 Python부터 설치하면 순서가 거꾸로 됩니다. 컴퓨터에 어떤 파일을
주고, 무슨 규칙으로 처리하며, 어떤 결과가 맞는지 먼저 정해야 합니다.

이 글에서는 부서별 지출내역 Excel 세 개를 결과 파일 하나로 만드는 업무를 사용합니다. 입력, 처리,
판단, 출력, 검증 다섯 칸을 채우면 Python이나 AI에게 무엇을 맡길지도 눈에 보입니다.

## 업무자동화란 무엇인가: 다섯 칸입니다

### 사람이 하던 반복업무를 입력부터 검증까지 정해진 순서로 다시 실행합니다

![부서별 Excel 파일 세 개가 처리와 판단을 지나 결과 통합문서와 숫자 검증표로 이어지는 자동화 다섯 단계](https://huggingface.co/datasets/eddmpython/eddmpython-media/resolve/main/objects/sha256/f5/f5fad4b2c39a012b33f50a82f27dfa5d7af71a070d2f0c693c95e83a7342f94b.png "왼쪽의 원본 파일부터 오른쪽의 검증 숫자까지 모두 정해야 자동화가 끝납니다")

업무자동화는 컴퓨터가 알아서 회사를 이해하는 일이 아닙니다. 사람이 하던 일을 입력, 처리, 판단,
출력, 검증 순서로 적고 컴퓨터가 같은 순서를 반복하게 만드는 일입니다.

예를 들어 매달 영업팀, 관리팀, 개발팀에서 지출내역 파일을 받는다고 가정합니다. 세 파일을 열어 열
이름을 맞추고, 금액이 큰 행을 표시하고, 부서별 합계를 만든 뒤 숫자가 맞는지 확인하는 일이 한 번의
자동화가 됩니다.

#### 설명 목록

- **입력:** 컴퓨터가 받을 원본 파일이나 값입니다.
- **처리:** 파일을 읽고 열을 정리하고 표를 합치는 순서입니다.
- **판단:** 금액이나 누락 여부를 나누는 조건입니다.
- **출력:** 사람이 열어 볼 결과 파일과 시트입니다.
- **검증:** 빠지거나 중복된 값이 없는지 확인하는 숫자입니다.

## 완성된 결과부터 비교합니다

### 원본 세 개와 결과 파일 하나를 먼저 보면 자동화할 이유가 바로 보입니다

![서로 다른 부서의 원본 Excel 세 개와 통합내역 및 부서별요약과 확인필요 시트를 가진 결과 파일 하나의 비교](https://huggingface.co/datasets/eddmpython/eddmpython-media/resolve/main/objects/sha256/20/20938f5d4176075be84c0c7dc31f8baa9bb6c4761e20ec59e43fa565e6262a3f.png "자동화 전에는 세 파일을 따로 열지만 자동화 후에는 한 결과 파일의 시트만 확인합니다")

자동화를 설계할 때는 완성 화면을 먼저 그리는 편이 쉽습니다. 왼쪽에는 원본 Excel 세 개가 있고,
오른쪽에는 `expense_result.xlsx` 하나가 있습니다. 결과 파일에는 통합내역, 부서별요약, 확인필요,
검증결과 시트가 들어갑니다.

이 비교를 먼저 하면 목표가 `Excel을 자동화한다`처럼 넓어지지 않습니다. 원본 세 개를 읽어 결과 파일
하나와 시트 네 개를 만든다는 구체적인 작업이 됩니다. 파일명과 시트명이 정해지면 출력 단계가
끝났는지도 확인할 수 있습니다.

#### 예시

- 원본: `영업팀.xlsx`, `관리팀.xlsx`, `개발팀.xlsx`
- 결과: `expense_result.xlsx`
- 결과 시트: `01_통합내역`, `02_부서별요약`, `03_확인필요`, `04_검증결과`

## 입력은 컴퓨터가 받을 자료입니다

### 파일 이름과 시트 및 열을 적으면 컴퓨터가 어디에서 무엇을 읽을지 정해집니다

![input 폴더 안의 Excel 세 파일과 각 파일의 일자 부서 항목 금액 비고 다섯 열이 한 입력 명세 카드로 연결된 모습](https://huggingface.co/datasets/eddmpython/eddmpython-media/resolve/main/objects/sha256/12/128ebb96e97c2ec884c5a22d8c374987238daf6a3f2c5c8161bcf522299b9260.png "입력은 Excel이라는 말이 아니라 폴더와 파일 수와 열 이름까지 적어야 실행할 수 있습니다")

입력은 업무를 시작할 때 컴퓨터가 받는 자료입니다. `Excel 파일을 읽는다`만 적으면 어느 폴더의 몇
개 파일인지 알 수 없습니다. `input` 폴더의 `.xlsx` 파일 세 개처럼 위치와 형식을 함께 적습니다.

파일 안에서 읽을 열도 정해야 합니다. 이번 예제는 `일자`, `부서`, `항목`, `금액`, `비고` 다섯
열을 사용합니다. 부서 열이 비어 있거나 금액에 `120,000원`처럼 글자가 섞일 수 있다면 그 상태도
입력 설명에 남깁니다.

#### 확인 목록

- 파일이 들어오는 폴더를 적습니다.
- 처리할 파일 확장자와 개수를 적습니다.
- 읽을 시트 이름과 열 이름을 적습니다.
- 비어 있거나 형식이 달라질 수 있는 값을 적습니다.

## 처리와 판단은 사람이 정한 규칙입니다

### 파일을 합치는 순서와 확인이 필요한 행을 나누는 조건을 따로 적습니다

![Excel 행들이 열 정리와 표 합치기 처리 단계를 지난 뒤 정상과 확인필요 두 갈래로 나뉘는 모습](https://huggingface.co/datasets/eddmpython/eddmpython-media/resolve/main/objects/sha256/27/2700f44fd59c735582e776678a745ff85d0070d7981dadb0a9ac8e8067295fa3.png "표를 바꾸는 처리와 조건에 따라 나누는 판단을 분리하면 수정할 규칙을 찾기 쉽습니다")

처리는 자료의 모양을 바꾸는 순서입니다. 파일을 하나씩 읽고, 필요한 열만 남기고, 원본 파일명을 새
열에 넣고, 세 표를 위아래로 합치는 동작이 처리에 해당합니다.

판단은 어떤 조건에서 결과를 나눌지 정하는 일입니다. 금액이 `100000` 이상이면 확인필요로 표시하고,
부서가 비어 있어도 확인필요로 보냅니다. Python의 조건문이나 AI는 이 기준을 정하지 않고 사람이 적은
기준을 그대로 실행합니다.

#### 예시

```text
처리: 파일 읽기 -> 열 정리 -> 출처파일 추가 -> 표 합치기
판단: 금액 >= 100000 -> 확인필요
판단: 부서가 비어 있음 -> 확인필요
```

## 출력은 파일이고 검증은 숫자입니다

### 결과 파일이 생긴 뒤 입력과 출력의 건수와 금액이 같은지 확인합니다

![결과 Excel 파일 옆에서 입력과 출력의 파일 수 행 수 금액 합계를 서로 맞춰 보는 검증 카드](https://huggingface.co/datasets/eddmpython/eddmpython-media/resolve/main/objects/sha256/9d/9d25d2a019f1d6cc4860c4376bcc0cc7e4c1202aca7d997f06ba4a7c61602bac.png "파일 생성은 실행 성공이고 건수와 금액 차이가 0인 것은 결과 검증입니다")

출력은 자동화가 만든 실제 파일입니다. 파일 이름과 시트 구성을 미리 적어 두면 실행 뒤 무엇을 열어야
할지 알 수 있습니다. 하지만 파일이 생겼다는 사실만으로 내용이 맞다고 말할 수는 없습니다.

검증에서는 입력과 출력의 숫자를 맞춥니다. 입력 행 수와 통합내역 행 수가 같고, 입력 금액 합계와
결과 금액 합계가 같아야 합니다. 같은 입력으로 다시 실행했을 때 행이 두 배가 되지 않는지도
확인합니다.

#### 확인 목록

- 입력 파일 수와 처리 파일 수의 차이가 `0`입니다.
- 입력 행 수와 통합내역 행 수의 차이가 `0`입니다.
- 입력 금액과 결과 금액의 차이가 `0`원입니다.
- 원본 파일의 내용과 수정 시각이 바뀌지 않습니다.
- 같은 입력으로 다시 실행해도 결과 행 수가 같습니다.

## 내 업무 하나를 다섯 칸에 적습니다

### 오늘 반복한 업무의 실제 파일과 규칙 및 확인 숫자를 한 줄씩 채웁니다

![비어 있는 입력 처리 판단 출력 검증 다섯 카드가 지출내역 업무의 파일명과 조건 및 숫자로 채워지는 모습](https://huggingface.co/datasets/eddmpython/eddmpython-media/resolve/main/objects/sha256/06/06582080fdce28fdc2354c382a155b908bc0a465a1850b32febcf11a9b4e6460.png "도구 이름보다 오늘 사용한 파일과 조건을 적으면 첫 자동화 설명이 완성됩니다")

지금 자동화할 업무 하나를 고릅니다. Python이나 AI 이름은 아직 적지 않습니다. 오늘 받은 파일,
직접 반복한 순서, 사람에게 물어본 조건, 마지막으로 만든 파일, 맞는지 확인한 숫자를 다섯 칸에 한
줄씩 적습니다.

아래 예시처럼 썼다면 첫 설계가 끝난 것입니다. 다음 글에서는 Python이 이 규칙을 어떻게 표현하는지
보고, 설치 없이 값을 바꿔 실행합니다.

#### 예시

```text
입력: input 폴더의 부서별 Excel 3개, 일자·부서·항목·금액·비고 열
처리: 파일을 읽고 열을 맞춘 뒤 출처파일을 추가해 하나로 합침
판단: 100000원 이상 또는 부서 누락이면 확인필요
출력: expense_result.xlsx의 통합내역·부서별요약·확인필요·검증결과 시트
검증: 입력과 출력의 행 수 및 금액 차이 0, 원본 변경 없음
```
