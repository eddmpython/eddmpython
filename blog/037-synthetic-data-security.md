`AI 합성 데이터 만드는 방법`의 목적은 원본을 조금 가리는 것이 아닙니다. 실제 사람과 회사 정보를
전혀 사용하지 않으면서 코드가 처리해야 할 열, 값 형식, 경계, 오류를 다시 만드는 것입니다.

합성 데이터가 있으면 AI와 코드를 함께 시험하면서도 원본 Excel은 공유 경계 안에 둘 수 있습니다.
이 글에서는 5행으로 정상, 10만원 경계, 취소, 잘못된 금액을 모두 재현합니다.

## AI에 보낼 정보와 보내지 않을 정보를 나눕니다

### 원본 레코드와 비밀값은 남겨 두고 업무 규칙과 가짜 값만 공유 영역으로 옮깁니다

![회사 원본과 비밀값은 잠긴 영역에 남고 업무 규칙만 합성 데이터로 이동하는 보안 경계](https://huggingface.co/datasets/eddmpython/eddmpython-media/resolve/main/objects/sha256/c7/c7c4f6c8ea1a1e29b52de742d5ea62751f5f2a6aa5db93b099155f19a6dc41e9.png "원본 행은 경계를 넘지 않고 열 구조와 처리 규칙만 합성 파일 제작에 사용됩니다")

이름만 `홍길동`으로 바꿔도 계좌번호, 이메일, 거래 메모, 내부 폴더 경로가 남아 있으면 안전한 합성
데이터가 아닙니다. 어떤 열을 지울지가 아니라 어떤 업무 동작을 재현할지부터 정합니다.

서비스 설정과 회사 정책에 따라 공유 가능한 범위가 다르므로 최종 판단은 조직의 보안 규칙을 따릅니다.
확신이 없으면 원본을 올리지 않고 담당자에게 확인합니다.

#### 예시

| 정보 | 합성 파일에 넣는 방법 | 공유 판단 |
|---|---|---|
| 실명, 사번, 계좌, 이메일 | `사용자-001` 같은 새 가짜 값으로 교체 | 원본 값 금지 |
| 거래 금액 | 규칙 검증에 필요한 새 숫자로 생성 | 가능 여부 확인 |
| 거래 메모 | `정상`, `경계`, `오류` 같은 설명용 값 사용 | 원문 금지 |
| 내부 서버와 폴더 경로 | `samples/input.xlsx` 같은 일반 경로 사용 | 내부 경로 금지 |
| API 키와 토큰 및 비밀번호 | 열과 값 자체를 만들지 않음 | 항상 금지 |

## 5행에 정상과 경계 및 오류를 모두 넣습니다

### 50000원과 99999원 및 100000원과 음수와 잘못된 금액을 한 번씩 만듭니다

![정상과 경계 직전과 경계값과 취소 및 오류 조건을 한 행씩 담은 5행 합성 Excel](https://huggingface.co/datasets/eddmpython/eddmpython-media/resolve/main/objects/sha256/61/6193b52e2320940745e2097621608c6215b8091c6534113ac5dd967d9d3d5b34.png "다섯 행이 서로 다른 처리 규칙 하나씩을 담당해 작은 파일로 전체 분기를 시험합니다")

합성 파일은 무작위 행을 많이 만드는 것보다 규칙마다 이유가 있는 행을 하나씩 만드는 편이 좋습니다.
아래 다섯 행은 금액 표준화, 10만원 경계, 취소 분류, 확인필요 분기를 모두 지나갑니다.

거래ID와 부서도 실제 값을 흉내 내지 않습니다. 가짜라는 사실이 분명한 규칙적인 이름을 사용하면 결과
Excel에 잘못 섞여도 실제 자료로 오해할 가능성이 줄어듭니다.

#### 예시

| 거래ID | 거래일 | 부서 | 금액 | 적요 | 검사 목적 |
|---|---|---|---:|---|---|
| 거래-001 | 2026-08-01 | 부서-A | 50000 | 정상 샘플 | 일반 거래 |
| 거래-002 | 2026-08-02 | 부서-A | 99,999원 | 경계 직전 | 일반 거래 |
| 거래-003 | 2026-08-03 | 부서-B | 100000 | 경계값 | 고액거래 |
| 거래-004 | 2026-08-04 | 부서-B | -1 | 취소 샘플 | 취소거래 |
| 거래-005 | 2026-08-05 | 부서-C | 확인 | 오류 샘플 | 확인필요 |

## 원본 없이도 같은 검증값을 만듭니다

### 정상 4행과 확인필요 1행 및 합계 249998원을 테스트로 고정합니다

![5행 합성 입력이 정상과 고액과 취소와 확인필요 결과 및 합계 검증으로 이어지는 모습](https://huggingface.co/datasets/eddmpython/eddmpython-media/resolve/main/objects/sha256/a2/a21da2b967cdab9712760663bdccdddbcb3ecf97a9ad4708dbcb8c92b5251a10.png "합성 입력의 각 행이 기대 분류와 숫자에 연결되어 원본 없이도 동작을 증명합니다")

합성 데이터도 기대 결과가 없으면 단순한 예시 파일일 뿐입니다. 각 행이 어느 결과로 가야 하는지와
전체 숫자를 먼저 계산합니다. 이번 샘플은 숫자로 바꿀 수 있는 4행이 정상 결과에 남고 1행은 확인필요로
갑니다.

정상 금액 합계는 `50000 + 99999 + 100000 - 1`, 즉 `249998`원입니다. 고액거래는 1행이고
취소거래도 1행입니다. 이 값이 테스트와 결과 Excel의 검증 시트에 모두 같아야 합니다.

#### 코드

```python
def test_synthetic_workbook_contract():
    report = build_report("samples/synthetic-five-rows.xlsx")

    assert len(report.normal) == 4
    assert len(report.review) == 1
    assert report.normal["금액"].sum() == 249_998
    assert len(report.high_value) == 1
    assert len(report.cancelled) == 1
```

## 공유 전에 파일과 화면을 한 번 더 검사합니다

### 열 이름과 셀 값 및 파일 경로와 화면 캡처를 사람이 최종 승인합니다

![합성 Excel과 터미널 로그 및 화면 캡처가 민감정보 검사표를 통과한 뒤 공유 승인되는 모습](https://huggingface.co/datasets/eddmpython/eddmpython-media/resolve/main/objects/sha256/fd/fd2861943e1008956826164d20a67bb9545b0132228337891a1531604b903d0a.png "자동 검사와 사람 확인을 모두 통과한 합성 자료만 공유 영역으로 이동합니다")

합성 Excel만 안전해도 충분하지 않습니다. 터미널 로그에 사용자 폴더가 보이거나 화면 캡처 뒤쪽에 회사
문서가 열려 있을 수 있습니다. 공유 묶음 전체를 열어 파일 내용과 경로 및 화면을 함께 봅니다.

자동 검사는 흔한 비밀 파일과 민감한 열 이름을 찾는 보조 수단입니다. 값의 의미까지 완벽히 판단하지
못하므로 마지막 공유 버튼은 사람이 눌러야 합니다.

#### 확인 목록

- 파일에 실명, 사번, 계좌, 전화번호, 이메일이 없습니다.
- `.env`, API 키, 토큰, 비밀번호가 없습니다.
- 회사명, 고객명, 내부 서버와 실제 폴더 경로가 없습니다.
- 5행 모두 가짜 값이며 실제 행을 섞어 쓰지 않았습니다.
- 같은 경계와 오류 및 기대 숫자를 재현합니다.
- 로그와 화면 캡처까지 직접 열어 확인했습니다.
- 조직의 AI 사용 정책에서 공유가 허용된 범위입니다.
