# 블로그 주제 전략

`marketingskills`의 content-strategy에서 **주제 선정과 각도**만 가져왔다. 캘린더 SaaS,
키워드 도구, SNS 배포 루프는 다루지 않는다.

## 먼저 읽을 것

- [productMarketing.md](productMarketing.md)
- 최근 발행 글 `blog/posts/*/index.md`
- `blog/posts/` 의 가장 큰 폴더 순번
- 지금 확인된 제품 변경, 실패, 화면

## 주제를 고르는 순서

1. 독자가 아직 모르는 상태로 겪는 질문 하나를 적는다.
2. 그 답을 이 저장소나 제품 화면에서 보여 줄 재료가 있는지 확인한다.
3. 재료가 없으면 주제를 버린다. 추측으로 쓰지 않는다.
4. 각도를 고른다.
   - **문제 각도**: 설치, 공시 확인, 표 반복 같은 고통으로 진입
   - **결과 각도**: 첫 실행, 첫 비교, 첫 자동화 같은 성공 장면으로 진입
   - **브랜드 각도**: 제품 이름을 이미 아는 사람만 대상. 기본값으로 쓰지 않는다.
5. `readerQuestion` 초안을 만들고, 제목 후보에 `operation.blogCopy` 게이트를 건다.

## 우선순위

같은 노력이면 아래를 먼저 쓴다.

1. 홈 제품과 직접 연결되고 설치 없이 따라 할 수 있는 글
2. 검색 의이 브랜드가 아닌 작업인 글
3. 내부 결정이나 실패를 독자 판단 기준으로 바꾸는 글

아래는 뒤로 미룬다.

- 제품 기능 나열
- 아직 공개 URL이 없는 약속
- SNS 확산만을 위한 짧은 홍보문

## 도구에서 Python 실습으로 연결

도구형 글은 독자가 업무 결과를 만드는 곳이고, Codaro는 그 기능을 Python으로 직접 만들고
입력을 바꿔 실행하는 곳이다. 학습 연결은 선택 사항이다. 모든 글에 수업을 요구하거나 Codaro
학습 과정의 존재를 블로그 발행 조건으로 삼지 않는다.

연결하기로 한 글은 다음 순서로 작업한다.

1. 도구에서 독자가 얻은 결과 하나를 고르고, 같은 결과를 만드는 Codaro 수업이 있는지 확인한다
2. 기존 수업을 보완하거나 Codaro 저장소에 공개 실습을 새로 작성한다. 유료 교안과 제품 코어는
   옮기지 않는다. 수업 원문, 실행 코드, 준비물과 검증은 Codaro가 소유한다
   블로그의 JavaScript 도구와 Codaro의 Python 실습은 구현 언어를 달리하되 공통 입력으로 같은
   결과를 만들어야 한다. 의미상 결과 일치와 섹션별 시각물 기준은
   [Codaro 학습 경험](https://github.com/eddmpython/codaro/blob/main/docs/skills/architecture/learning-experience.md)이 소유한다
3. 각 실습 섹션에 시작 위치, 예제 입력 또는 다운로드, 실행 방법과 확인할 결과를 함께 제공한다.
   Web과 Local의 실행 범위를 구분하고 실제 파일, 패키지나 OCR 실행기가 필요하면 먼저 준비시킨다
4. 블로그에서 설명한 것과 같은 개념을 보여 주는 공개 이미지만 재사용한다. 이미지 공유 절차는
   [blogMedia.md](blogMedia.md)의 Codaro 연결 계약을 따른다
5. Codaro의 실제 수업 주소와 실행 결과를 확인한 뒤 블로그 끝의 `더 해 볼 것`에 직접 연결한다.
   링크 문구에는 배울 행동과 만들 결과를 적는다. 홈페이지 링크로 수업 연결을 대신하지 않는다
6. 수업에서도 원래 도구로 돌아갈 링크를 제공한다. 원본 도구 사용법과 Python 구현법은 구분한다.
   수업을 읽은 것만으로 원본 도구의 미구현 기능이 제공된다고 서술하지 않는다

공개 연결 전에는 수업 진입, 필요한 자료 접근, 코드 실행과 결과 저장을 실제로 확인한다. 존재하지
않는 수업을 예고 링크로 붙이지 않으며, 연결 이후 주소나 자료가 바뀌면 양쪽 참조를 함께 갱신한다.

## 한 분기 목록을 만들 때

표로 세 칸만 둔다.

| 독자 질문 | 확인된 재료 | 제목 각도 |
|---|---|---|
| ... | 화면/코드/글 링크 | 문제 또는 결과 |

목록이 다섯 줄을 넘으면 아직 재료 없는 줄을 지운다.

## 롤백

주제 목록은 커밋된 메모나 이슈에만 있다면 해당 문서를 되돌린다. 이미 쓴 글 파일은
`operation.blogCopy`로 제목만 고치거나 글을 삭제한다.
